`main` 分支更新后，GitHub Actions 校验已提交的题库与专题 PDF，构建干净题块与完整专题册，再整理为 `output/site` 发布到 GitHub Pages。发布目录只复制当前引用的题图和网页资源，保留干净专题册，排除作为构建输入的原专题册，并检查总大小不超过 1,000,000,000 字节；仓库素材不删除。网页、题目数据、原图、专题 PDF、整理脚本均在同一仓库保存；可重建的 PDF、临时预览文件与登录凭据不提交。

九个专题：有机化学、高分子化学、晶体化学、无机综合与结构推断、方程式与元素化学、热力学与化学平衡、电化学、动力学、分析化学。

当前收录第39届22份、第38届24份、第37届28份、第36届25份、第35届26份、第34届17份、第33届18份、第32届12份、Chemy联赛24届试题，共1933道完整大题。每道大题只设置一个主专题。九个专题提供累计题目册、答案册，保留原卷字体、结构式、评分和来源。既有来源、字形、原图及题答配对检查记录见 `data/audit_report.json`；检查范围与局限见 [docs/final-review.md](docs/final-review.md)。历史检查记录不代表后续修改已通过复核，也不能代替逐图目视核对。

网页正文与表格为 HTML；图形从原 PDF 提取，未使用 AI 生成或人工重绘化学结构。电化学图从原 PDF 的显示内容提取，保留原题对纵轴的处理；有机图保留原矢量路径及原图标签。页面背景装饰不属于题目图形，不随图导入。原文件未修改。

## 本地预览

在仓库根目录打开终端。浏览已有题库只需 Python 3；要测试单题、选题、AI 组卷或完整专题册的 PDF 下载，请先完成下面的一次性准备。

源码 ZIP 和 Git 仓库不包含可重建的 `dist/export-parts/`。使用 Python 3.11+ 安装导出依赖，再从已提交的专题册生成分题文件与供下载的干净完整专题册：

```sh
python -m pip install -r scripts/export-requirements.txt
python -X utf8 scripts/build_export_parts.py
python -X utf8 scripts/check_release.py --pdfs --parts
```

Windows 可用 `py -3` 替代 `python`；macOS / Linux 通常使用 `python3`。首次准备会处理完整题库，后续运行复用有效缓存；专题册或导出规则变化后重新运行。此流程不需要重录原卷，也不需要系统宋体或 Poppler。构建依赖包含 PyMuPDF，其 AGPL/商业双许可见[权利与许可说明](docs/rights.md)。

Windows（PowerShell）：

```powershell
py -3 -m http.server 8765 --bind 127.0.0.1 --directory dist
```

macOS / Linux：

```sh
python3 -m http.server 8765 --bind 127.0.0.1 --directory dist
```

打开 http://127.0.0.1:8765/，保持终端运行，按 Ctrl+C 停止。Windows 未安装 `py` 启动器时可把 `py -3` 换成 `python`。直接双击 HTML 使用 `file:` 协议，浏览器不能正常读取题库和启动 PDF Worker；请使用上面的本地地址。

修改后的轻量检查：`python -X utf8 scripts/check_release.py --pdfs`（Python 3.11+；macOS / Linux 可用 `python3`）。该命令检查题目、编号、图片引用、题答索引和专题 PDF 摘要，不写入题库。完整生成分题文件与干净专题册后增加 `--parts`，检查输入/生成器摘要、全库覆盖、分题文件字节及页块元数据；抽样生成会被判为未完成。开发、数据来源与重建步骤见 [贡献与维护指南](docs/contributing.md)。

## 网站使用

“AI 组卷”按细知识点选取现有完整大题，默认 5 题。支持同义词、候选知识点确认、题量和来源筛选、删题、单题替换及重新组卷。相关题不足时按实际题量生成，不重复凑题。参考答案默认折叠，知识点对应的小问和关联理由放在答案内；可分别下载题目与答案 PDF，也可分别打印。PDF 保留原题、原答案、专题编号、来源、原字形与结构图；新增关联说明与原答案明确区分。

知识点来自 AI 对题干、参考答案及原图的预先阅读。网页显示真实已分析题量，只在已分析题目内选题；未完成全库分析时不将检索结果宣称为全库结果。默认使用本地索引选题；可配置独立后端，由 DeepSeek Agent 理解自然语言需求并选择经过审核的原题，密钥仅存放在后端。索引工作流见 [docs/ai-paper.md](docs/ai-paper.md)，API 接入、测试与公开网站部署步骤见 [docs/deepseek-deployment.md](docs/deepseek-deployment.md)。

首页展示作者的建站缘起与题库使用建议。选择专题后，可按“届次 → 试卷 → 题目”展开目录，筛选来源或输入专题题号跳转。顶部查题窗口支持搜索题目标题与题干，可限定专题、届次、试卷，并按需纳入答案文字。多个关键词用空格分隔；英文大小写与化学式上下标兼容。搜索结果展示来源和关键词片段，点击定位原题，“返回搜索结果”保留搜索位置。多数原图内部文字未进行 OCR，不能直接检索。

每题提供“下载本题 PDF”。“按题目 / 试卷选题”打开可勾选的届次—试卷—题名清单，支持整卷、整届选择。专题切换为“全部专题”后，可选择某一届所有试卷的全部题目；名称搜索及专题题号范围（如 `12、15-18`）可缩小列表，“只看已选”便于检查、删减。分组选择只作用于当前筛选范围，部分选中显示半选状态。选择跨专题、跨筛选保留，按专题与专题题号排序，可分别下载题目 PDF 和答案 PDF，两份文件使用同一组选题及顺序。题与题连续排版，不强制逐题分页，长题仅在文字与图形之间的空白处换页。原字体、公式、图形、编号与出处保留。浏览器只读取所选题目的分题文件并在本地排版；关闭下载窗口可取消，失败后可以重试。

“答案 PDF”是所选题目的参考答案与原评分内容，不保证重复包含完整题干；需要题目与答案时分别下载两份。AI 组卷附加的关联说明与原答案明确区分。

专题题目与答案 PDF 为整个专题的累计册，不随网页筛选缩小范围。两册均按专题题号紧凑接续排版，不因换题或换试卷另起一页；页满时在文字与图表之间自然换页。题号、出处、原字形与 Chemy 水印保留，页码和题目书签随新排版更新。界面、搜索与复核方法见 [docs/interface.md](docs/interface.md)。

题目阅读区、按题生成的 PDF，以及专题题目册和答案册均显示完整 Chemy 图案水印。水印正向居中、浅灰显示，原题文字与图形保留；PDF 每页一枚，连续排版不受影响。更新旧题册水印可运行 `python scripts/pdf_watermark.py`；重新合并题册会自动添加。

## 内容维护

- `dist/questions.json` 保存原卷题目、答案和来源，不覆盖原始题号。
- `dist/numbering.json` 是网站与 PDF 共用的专题编号表。每个专题从 1 开始；筛选试卷不会重编号。
- `dist/presentation.json` 保存展示内容：大题第 N 题，小问 N-1、N-2，多层小问 N-2-1。原题号只在来源中标注。
- `dist/downloads` 保存九个专题的题目册、答案册构建输入，共 18 份；网页下载使用生成后的 `dist/export-parts/*-book.pdf` 干净完整专题册。卷首提示、常数及评分说明不展示；题干内必要提示和逐题评分保留。
- `scripts/rebuild_numbering.py` 批量更新编号、含题号的原图局部标签和 PDF。只复用或替换编号字形，化学结构、反应箭头与图表不重绘。缓存按编号计划复用。
- `scripts/check_release.py` 可在没有录入缓存的源码副本中核对当前全部题目、展示、编号、资产引用、题答索引和 PDF 摘要。它不检查化学正确性或图像视觉完整性。
- `scripts/audit_numbering.py` 进一步核对编号、编号区域之外原图像素和打印索引，但依赖原录入缓存及历史 Git 基线；运行条件见贡献指南。
- `data/print_index.json` 记录各题在累计打印册中的编号、来源和页码。
- `dist/export-index/` 保存各题在题目册及答案册中的裁剪范围与安全换页边界。题册重新生成后，运行 `scripts/build_export_index.py` 和 `scripts/build_export_index.py --answers` 同步两种索引；索引重建依赖 pdfplumber、pypdfium2、numpy。
- `python scripts/pdf_version.py` 根据全部专题册内容同步 PDF 版本与索引版本，不加载旧排版器或系统字体。它不重算坐标，需先生成正确题册与索引，再运行分题构建。
- `scripts/build_export_parts.py` 从已提交题册和索引构建 `dist/export-parts/`：移除题块之外的隐藏绘图内容、裁剪重复层并按需保留字体，生成每道题的题目/答案小 PDF、供完整专题下载的 `*-book.pdf` 及构建清单。浏览器 Worker 使用本地 pdf-lib 直接复制题块绘制内容，避免再次把完整专题页作为裁切 Form 嵌入。分题文件属于忽略的构建产物，由本地准备命令或 Pages 工作流生成，无需上传用户选题。

第39～32届及联赛的来源 PDF、32届答案补正和补正工作源保存在 `sources/`；文件来源和摘要见 `sources/manifest.json`、`data/editions.json`。补正工作源属于派生文件，原始答案另行保留。归档的首套打印册保留在 `data/book_bases/`。图文复核记录见 `data/audit_report.json`，展示编号与打印册检查见 `data/numbering-audit.json`。

更新来源内容或分类前，请按[贡献指南](docs/contributing.md)区分网页修订、图片修正和整册重建，并准备相应缓存。`rebuild_numbering.py`、`audit_numbering.py` 并非干净 ZIP 中可直接完成的全库一键构建。当前完整题库不能直接运行旧的首套专用脚本覆盖，旧脚本与归档保留供来源追溯。

原参考答案中已确认的编号笔误按原题对应：39 届第 1 套第 6 题答案的 6-5 对应原题 6-4；36 届第 25 套第 4 题答案单列的 9-4 对应该题第 4 小问。原电势代入式和 Na-O 高度的既有来源校注继续保留。试剂当量、反应编号、谱线编号与化学结构标号不作为小问题号替换。
