# 网站目录与搜索

首页直接显示作者提供的“写在前面”和“题库与使用”全文。专题侧栏、首页“浏览专题题目”链接进入题库；CHEMY 字标和“介绍与使用”返回首页。介绍是静态 HTML，题库尚未加载或暂时失败时仍然可以阅读。

界面采用白底、浅灰专题栏与绿色选中提示。界面使用微软雅黑等系统黑体；介绍正文、题目与答案采用宋体 / Times 排版，介绍每段首行缩进两个汉字。输入、筛选和下载按钮使用 9px 圆角。assets/chemy-wordmark.png 直接复制自项目已有的透明 CHEMY 字标，未重绘。

## 分层目录

当前专题按届次 → 试卷 → 专题题号排列；Chemy 联赛保持独立来源。届次与试卷筛选同时作用于目录和阅读列表。没有原始标题的题目以题干前 42 个字符显示“题干”简述，不改原题正文。输入专题题号时，可跨当前筛选定位该专题中的对应题目。专题编号沿用 numbering.json，筛选后不重编号。

目录跳转地址例如 `?question=chemy39-1-6#electrochemistry`（以实际题目 id 为准），支持刷新、浏览器前进后退和复制链接。电脑宽度达到 1200px 时显示专题、目录、阅读三栏；平板的目录、手机的专题与目录使用可关闭窗口，不挤压题干。窗口关闭后恢复背景滚动和键盘焦点。

## 关键词查找

顶部搜索入口或 Ctrl / Command + K 打开查题窗口。默认搜索全部九个专题的标题和题干，可限定专题、届次、试卷；勾选后才额外搜索答案。多个空格分隔的关键词需同时出现；不区分英文大小写，统一 Unicode 上下标、全角字符和常用减号。HTML 上下标取连续文本，因此 `LiFePO4` 与 `LiFePO₄` 可以匹配。

结果显示专题题号、标题或题干简述、原试卷来源和含关键词片段。标题直接匹配优先；只有答案匹配的结果明确标注。片段和高亮仅用于搜索结果，原题正文和原图不改。结果每次追加 60 项。点击后定位原题，参考答案保持折叠；“返回搜索结果”恢复关键词、筛选和结果滚动位置。

只检索已有文字与有实义的图片替代文字，未进行 OCR；多数原图内的试剂、结构式和文字无法通过关键词直接查到。

## 加载与检查

题库数据不再强制绕过浏览器缓存。图片按需读取；答案 HTML 在展开时插入；远离阅读区域的题目使用 content-visibility 降低排版开销。搜索索引首次使用时分批构建。加载失败时保留介绍并提供重试入口。

专题 PDF 始终提供整个专题的累计题目册与答案册，按钮名称和提示明确其范围，不随届次或试卷筛选变更。

`scripts/test_interface.cjs` 使用 Playwright 检查首页、目录、筛选、编号跳转、深链接、关键词/化学式/答案搜索、搜索返回、手机和平板窗口、焦点、快捷键和失败重试。先用 HTTP 服务提供 dist/，再运行测试；默认测试地址为 http://127.0.0.1:8765/，可用 CHEMY_TEST_URL 覆盖。PLAYWRIGHT_MODULE 可指定 Playwright 包路径，CHEMY_BROWSER_CHANNEL 可指定已安装的浏览器通道。检查报告与截图写入忽略的 output/，复核摘要保存为 data/interface-review.json。
