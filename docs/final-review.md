# Chemy 题库录入复核

收录范围为第39～32届年度合集及Chemy联赛第1～24届，共196份、1933道完整大题。每题保留一个主专题；九个专题内的大题、小问使用同一编号表，网页与18册专题题答PDF保持一致。第32届官方补正对应的10道题按原补正文档替换，保留补正页码与原始来源。

## 检查范围

- 逐题核对原始题、答索引键及来源PDF哈希，避免遗漏、重复和跨卷配对。
- 对原生文字字形逐段比较；所有原图裁片与原页逐像素比较，含箭头和结构式。
- 检查重新编号后的文字与原文等价，含小字号答案题号、三位题号、希腊字母化学表达式及交叉引用。
- 检查题号图中的非题号像素保持原样。
- 对18册PDF的全部合并页面及绘图资源、透明蒙版进行原生章节对照，并检查PDF结构、题目目录与来源页范围。
- 目视检查全部专题册首、边界异常、各届转换及官方补正样页。不是人工逐页重读全部4110页，也不代替对命题组原始答案的化学正确性评审。
- 发布后核对六份网站核心文件、变更图像及全部18个公开PDF下载的字节哈希。
