# 题库分类与录入规范

## 分类

一整道大题只设一个主专题，保留所有小问，不拆分跨专题大题。

无机综合题以确定未知物的组成、连接或空间结构为主线时，归入“无机综合与结构推断”；以元素性质、反应规律和方程式为主线时，归入“方程式与元素化学”。结合整题任务与分值判断，不因为局部出现一道结构小问就改变主专题。有机合成与机理题归入有机化学。

模拟试题1：第1题归入方程式与元素化学；第2、3、4题归入无机综合与结构推断。其他六题保持原归属。

## 后续批量流程

1. 按套处理：一次读取原卷题干、答案和题号，确认大题边界、答案对应及主专题，保存到清单。
2. 脚本生成：提取原生文字，批量裁取原图，复用现有网页模板，从原PDF区域生成专题打印册。原卷保持只读；不让模型逐字转录或重绘结构，不再逐题设计页面。
3. 集中核对：程序检查题号、字符覆盖、资源路径与数据完整性；对每道新题做一次原卷图文对照，并检查新生成打印册的所有页面。重点保留箭头线、上下标、电荷、虚实楔键、表格、跨页衔接、答案和评分。异常记录坐标或规则，下次复用修正。
4. 批次发布：一批核对完成后统一提交、部署和核验公开链接，避免逐题部署。归档原文件、边界、分类、脚本及输出，方便追溯。

## 省时与省token的边界

- 模型主要处理分类、边界与异常判断；文字提取、化学式位置、图像裁切、PDF合并、数据检查交给脚本。
- 原生PDF不用OCR。源文件及处理版本一致时复用缓存；源文件变化或缓存不完整时重新提取，防止误用旧卷缓存。
- 原图输入与裁切坐标未变、输出摘要一致时跳过重新编码。同一页的多个图连续裁取，减少页面重复读取。
- 新题集中核对一次；修改后只复核受影响的题目、图形和打印册。已验证且内容未变的部分沿用结果。
- 改分类走元数据同步，不重新提取正文、答案或原图。PDF可按专题增量生成，并只解析实际需要的答案页面。
- 图文核对不能省略；速度提升来自减少重复处理。脚本耗时不等于整套新题录入耗时，token节省比例须在后续同规模批次中观察。

## 第一套卷现有命令

完整导入：`python scripts/import_paper1.py`。该命令会自动复用有效文字、页面及原图缓存。已认可的第6、8题模板仍保留。

仅同步分类与元数据：`python scripts/import_paper1.py --metadata-only`。

仅生成指定专题PDF：`python scripts/make_pdfs.py --topics elements inference`。不传`--topics`时生成所有有题目的专题。

新卷需要先建立相应边界清单，再复用上述流程；现有脚本的页码及例外规则目前仅适用于模拟试题1。


## 第39届全套增量导入

`data/import_plan.json` 保存完整大题的单一主专题。`scripts/scan_library.py` 一次缓存两份原卷的原生文字、图形坐标和题号，`scripts/import_library.py N` 增量录入第N套，`scripts/build_library_pdfs.py N` 更新累计专题PDF，`scripts/publish_library.py N` 提交GitHub并等待Pages部署完成。第1套样例正文、答案及图形保持不变。第一套旧脚本仅用于重建样例，不可直接运行覆盖全套数据。

按用户2026-09-30的要求，先逐套录入和发布，全部录完后统一检查图文完整性及题目与答案对应关系；录入中的 `reviewed: false` 如实保留，不能提前标为复核完成。缓存和临时文件不上传。
