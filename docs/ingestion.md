# 题库分类与录入规范

## 分类

一整道大题只设一个主专题，保留所有小问，不拆分跨专题大题。

无机综合题以确定未知物的组成、连接或空间结构为主线时，归入“无机综合与结构推断”；以元素性质、反应规律和方程式为主线时，归入“方程式与元素化学”。结合整题任务与分值判断，不因为局部出现一道结构小问就改变主专题。有机合成与机理题归入有机化学。

模拟试题1：第1题归入方程式与元素化学；第2、3、4题归入无机综合与结构推断。其他六题保持原归属。

## 后续批量流程

1. 一次扫描原卷，缓存原生文字、图形坐标、大题边界和题号；同一届题目与答案按套号、原题号配对，确定一整道大题的单一主专题。
2. 按套增量录入：提取原生文字，按原图坐标裁取图形，不OCR、不重绘；复用现有网页正文样式和PDF版式。
3. 录入时只做低成本程序检查：届次命名隔离、题号唯一、生成图片能解码、引用路径存在、文件摘要及原图坐标可追溯。每张新图使用包含届次和SHA的不可变文件名。
4. 一套录完后提交并部署GitHub Pages，核验在线数据和图片实际字节后再报告上线。发布权限或网络阻断时继续本地录入，明确区分本地与线上进度。
5. 根据用户最新要求，全部35、36、39届录完后统一进行原卷图文、题目与答案对应及打印册复核；之前不逐套进行模型视觉复核、不提前标记reviewed。

## 省时与省token的边界

- 模型主要处理分类、边界与异常判断；文字提取、化学式位置、图像裁切、PDF合并、数据检查交给脚本。
- 原生PDF不用OCR。源文件及处理版本一致时复用缓存；源文件变化或缓存不完整时重新提取，防止误用旧卷缓存。
- 原图输入与裁切坐标未变、输出摘要一致时跳过重新编码。同一页的多个图连续裁取，减少页面重复读取。
- 全部届次完成后集中核对一次；修改后只复核受影响的题目、图形和打印册。已验证且内容未变的部分沿用结果。
- 改分类走元数据同步，不重新提取正文、答案或原图。PDF可按专题增量生成，并只解析实际需要的答案页面。
- 图文核对不能省略；速度提升来自减少重复处理。脚本耗时不等于整套新题录入耗时，token节省比例须在后续同规模批次中观察。

## 第一套卷旧命令（不得覆盖现有完整题库）

完整导入：`python scripts/import_paper1.py`。该命令会自动复用有效文字、页面及原图缓存。已认可的第6、8题模板仍保留。

仅同步分类与元数据：`python scripts/import_paper1.py --metadata-only`。

仅生成指定专题PDF：`python scripts/make_pdfs.py --topics elements inference`。不传`--topics`时生成所有有题目的专题。

旧的第一套工具仅适用于已认可样例；后续卷子使用下面的多届次流程。


## 第39届全套增量导入

`data/import_plan.json` 保存完整大题的单一主专题。`scripts/scan_library.py` 一次缓存两份原卷的原生文字、图形坐标和题号，`scripts/import_library.py N` 增量录入第N套，`scripts/build_library_pdfs.py N` 更新累计专题PDF，`scripts/publish_library.py N` 提交GitHub并等待Pages部署完成。第1套样例正文、答案及图形保持不变。第一套旧脚本仅用于重建样例，不可直接运行覆盖全套数据。

按用户2026-09-30的要求，先逐套录入和发布，全部录完后统一检查图文完整性及题目与答案对应关系；录入中的 `reviewed: false` 如实保留，不能提前标为复核完成。缓存和临时文件不上传。

## 多届次录入与恢复

`data/editions.json` 指定原始PDF；`CHEMY_EDITION` 指定当前处理届次（默认39）。第36、35届主专题分别保存于 `data/import_plan36.json`、`data/import_plan35.json`。35、36届的题目ID、原图文件名、边界清单和打印分册均按届次隔离，第39届第1套既有正文、答案与原图保持不变。

顺序运行 `python -X utf8 scripts/scan_library.py`，再运行 `python -X utf8 scripts/process_batch.py --start N --end M`。在发布被阻断时可显式加 `--local-only`；恢复后再发布并验证，不得把本地完成报为公开上线。跨届次的专题PDF按39、36、35届及原套号顺序累计。已认可的第一套PDF分册原字节归档于 `data/book_bases/`，其余分册为可从原卷重建的缓存。

恢复前读取 `WORK_STATE.md` 和 `data/library_manifest.json`，避免重复导入已完成的套卷；不能只根据最后一个套号判断届次。最终完整范围为73套、713道大题（39届22套210题、36届25套253题、35届26套250题）。

## 本批最终复核与原图边界

全部录入结束后运行 `python -X utf8 scripts/audit_library.py`：核对三届源文件摘要、713题题号配对、原生字形覆盖、裁图原始像素及打印册分册内容。`data/audit_report.json` 明确记录自动检查与视觉检查范围，不能把样页抽查表述成逐页人工阅读。

`data/source_exceptions.json` 保存经原页确认的浮动插图、特殊答案示意图和背景瓦片摘要。浮动图按完整原图矩形提取，正文避开该矩形；打印册用联合裁切保留跨题头的图形，同时避免带入下一道题。纯白填充、无描边的题头背景矩形不是图形。未映射数学字形保留原卷显示，不推测替换，不重绘。

最终异常修正可只重录受影响套卷、运行 `scripts/build_library_pdfs.py N --parts-only`，再运行一次 `scripts/build_library_pdfs.py --merge-only`；不用在每套修正后重复合并18册。背景识别规则改变时只清除相关页的清理渲染缓存。第一套样例和12份已认可打印分册保持原字节。
