# 对话式 AI 智能组卷需求

本文记录 Chemy 对话式 AI 智能组卷的产品决定。现有组卷行为见 [AI 知识点组卷](ai-paper.md)。

## 对话式组卷

- 教师用自然语言描述组卷需求，并可在后续对话中修改当前试卷。
- DeepSeek API 是大语言模型接入选项。AI 理解教师意图，对现有题库进行语义检索和筛选，组合选中的题目，并组织试卷结构和题目顺序。
- 所有题目均选自现有题库。题干、选项、答案和解析均须取自题库。AI 不得编题、改写原题或补造题库缺失的题目内容。
- AI 可以生成知识介绍、梳理知识点。生成的知识讲解与原题及其答案、解析分开呈现。

## 多轮编辑与换题（方案 B）

教师可以通过对话要求增加、删除或替换题目。新增和替换的题目仍须从现有题库选取。编辑以当前试卷为基础，保留本次指令未涉及的题目。

换题时，AI 同时考虑教师对该题的要求和整卷的知识点覆盖、难度梯度及题型平衡。例如，教师说“第 5 题太简单，换一道更难的，其他题不动”，AI 应结合整卷选择符合要求的题库题目替换第 5 题，保留其余题目及其顺序。

## 不依赖 Render 的部署

GitHub Pages 可发布 `dist/` 中的静态网页。对话式组卷还需要运行 `server/agent.mjs`，由服务端使用 `DEEPSEEK_API_KEY` 调用 DeepSeek。密钥通过服务端环境变量注入。

- 保留 GitHub Pages 时，在独立的 HTTPS 后端配置 `ALLOWED_ORIGINS=https://brucejllpku.github.io`。验证后端后，再把 `dist/ai-config.json` 的 `mode` 改为 `deepseek`，`backendUrl` 设为后端的 HTTPS Origin。
- 同域部署时，在服务器上保留完整的 `dist/`，使用 Node.js 22 或以上运行 `node server/agent.mjs`。设置 `NODE_ENV=production`、`SERVE_STATIC=true`，并把 `ALLOWED_ORIGINS` 设为 Chemy 的 HTTPS Origin。服务默认监听本机 8788 端口，由 HTTPS 反向代理转发网页及 API 请求。服务会自动为网页提供同域的 DeepSeek 配置。

上线验收应在中国大陆普通网络上打开网页，完成一次实际出卷和换题。`/health` 的 `configured: true` 仅表示服务读到了密钥。

## 讲义与下载（2026-11-06）

- 知识介绍默认根据最终入卷题目生成，按简明教材逻辑合并考点，不逐题呼应。通常 3–5 节，正文约 350–750 字，公式另计；允许教师继续修改或删除。
- 讲义与题目连续排列，保留宋体 / Times New Roman、字号与行距。小标题、正文、独立公式统一排版；变量斜体、上下标保留。
- Word 分别下载题目与答案，题目包含卷首讲义。文本和原生表格可编辑，原题图片作为图片保留。A4 排版，自动页码，标题和后文衔接。
- 下载与打印集中在一个菜单，支持题目跳转、展开全部答案、最近 15 次修改的撤销。撤销仅在当前页面会话有效，恢复题目和讲义。
- 生成失败、取消和重组失败保留已有试卷；失败后提供重试，不自动重复付费调用。DeepSeek 模式的换题按钮交给模型处理并同步调整讲义。
- 上述决定取代此前关于默认知识介绍、撤销和分开呈现的待确认项。

## 验证与限制

服务回归：node --test scripts/test_deepseek_agent.mjs。
浏览器回归：node scripts/test_ai_workspace.cjs，需 Playwright、JSZip、Chrome 与本机预览服务。覆盖字体、公式、手机布局、撤销、重试、停止、Word/PDF 和打印。
Word 样稿使用 Microsoft Word 导出 PDF 检查。真实 DeepSeek 晶体化学样例用于检查结构与写作要求。

GitHub Pages 发布静态界面；公网 DeepSeek 仍需可访问后端，本机服务不会随静态页面推送自动上线。多轮跨主题扩展候选范围仍待完善。
